# AutoML Lite Product Overview

AutoML Lite is a lightweight, production-ready automated machine learning library that simplifies the entire ML pipeline from data preprocessing to model deployment.

## Core Purpose

Automated machine learning for non-experts that handles:
- Automatic problem type detection (classification, regression, time series, clustering)
- Intelligent preprocessing and feature engineering
- Smart model selection from 15+ algorithms
- Hyperparameter optimization using Optuna
- Ensemble methods and model interpretability

## Key Features

- **Zero Configuration**: Works out of the box with sensible defaults
- **Production Ready**: Deep learning (TensorFlow/PyTorch), time series (ARIMA, Prophet, LSTM), experiment tracking (MLflow, W&B)
- **Comprehensive Reporting**: Interactive HTML reports with visualizations, feature importance, and SHAP analysis
- **Multiple Interfaces**: Python API, CLI, and interactive terminal UI

## Target Users

- Data scientists for rapid prototyping
- ML engineers for production development
- Analysts for quick insights
- Students learning ML concepts
- Startups building MVPs

## Supported Problem Types

- Binary and multi-class classification
- Regression
- Time series forecasting
- Deep learning tasks

## Performance Characteristics

- Feature engineering: 11.6x feature expansion (20→232 features)
- Automatic feature selection for optimal performance
- Ensemble methods for improved accuracy
- Configurable time budgets (60s to 1800s+)
